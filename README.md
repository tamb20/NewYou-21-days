# تحدي ٢١ يومًا لبناء نسخة أفضل منك

نسخة محدثة من البرنامج التفاعلي تشمل أربعة جوانب:
- الجانب الروحي
- الجانب الرياضي
- الجانب الفكري والثقافي
- الجانب الاجتماعي

## الملفات
- index.html
- style.css
- script.js

## المزايا
- متابعة يومية لمدة ٢١ يومًا
- نسبة إنجاز لكل جانب
- نسبة إنجاز كلية
- تعليق يومي وتعليق نهائي
- شهادة اجتياز فخمة وجذابة باسم المشارك
- حفظ البيانات محليًا في المتصفح
- خط Jannat/Janna داخل الكود

## الفيديو التعريفي

تمت إضافة مكان مخصص لفيديو قصير في بداية الصفحة.

طريقة الاستخدام:
1. ضع الفيديو داخل مجلد `assets`.
2. غيّر اسم الفيديو إلى:
   `intro-video.mp4`
3. ارفع مجلد `assets` مع الملفات إلى GitHub.
4. سيتم تشغيل الفيديو تلقائيًا داخل الصفحة عبر زر التشغيل.

## نص مقترح للفيديو التعريفي 30–60 ثانية

هل تريد أن تبني نسخة أفضل منك خلال ٢١ يومًا؟

هذا التحدي يساعدك على متابعة تقدمك في أربعة جوانب مهمة:
الجانب الروحي، الرياضي، الفكري والثقافي، والاجتماعي.

كل يوم تدخل إلى الصفحة، تختار اليوم، وتحدد المهام التي أنجزتها.
ستظهر لك نسبة إنجاز كل جانب، بالإضافة إلى نسبة تقدمك الكلية.

وفي نهاية ٢١ يومًا، إذا أكملت رحلتك، ستحصل على شهادة اجتياز باسمك
مع تقييم شامل وتعليقك الشخصي عن التجربة.

ابدأ بخطوة صغيرة، واستمر يومًا بعد يوم.
فالتحسن الحقيقي لا يحدث دفعة واحدة، بل بعادة صغيرة تتكرر بصدق.


## الفيديو التعريفي المرفق

تم تضمين فيديو تعريفي قصير داخل:
`assets/intro-video.mp4`

الفيديو مدته تقريبًا 48 ثانية ويشرح فكرة البرنامج وطريقة استخدامه بشكل مبسط.


## التحديث الصوتي

تم دمج التعليق الصوتي داخل الفيديو:
`assets/intro-video.mp4`

كما تم حفظ نسخة من الصوت داخل:
`assets/voiceover.mp3`

مدة الصوت: 69.5 ثانية.
مدة الفيديو الأصلي قبل الدمج: 56.0 ثانية.
